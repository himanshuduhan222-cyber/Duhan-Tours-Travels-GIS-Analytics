# ✈️ Duhan Tours & Travels — Spatial GIS & Executive Recovery Analytics

An end-to-end GIS spatial analysis and interactive executive dashboard evaluating post-pandemic network retrenchment (-44.4% shrinkage) for **Duhan Tours & Travels**.

---

## 📌 Executive Summary

Following post-2020 market disruptions, Duhan Tours & Travels experienced a **44.4% network shrinkage**, discontinuing 4 out of 9 core travel corridors (**Srinagar, Kochi, London, Singapore**) originating from the **New Delhi (DEL) Hub**.

This repository provides:
1. **QGIS Cartographic Layouts:** High-resolution (300 DPI) spatial coverage maps displaying active vs. dropped travel boundaries.
2. **5-Whys Failure Analysis:** Root-cause diagnostic framework analyzing passenger drop-off drivers.
3. **Reactive Financial Simulator:** Real-time web application featuring dynamic sliders, P&L waterfall charts, and Web Speech API voice synthesis.
